=================================================

Goal: git pull works in:
  ~/storage/shared/!simon/obsidian/development/Sudoku

Plain Termux cannot run the Origin CLI (loader error e_type 2).
So login runs once inside Ubuntu proot. Git day-to-day stays in Termux.


ONE-TIME AUTH (two Termux tabs)
-------------------------------
Tab A:
  proot-distro login ubuntu --termux-home
  export PATH="/root/.local/bin:$PATH"
  origin auth login

When the https://cursor.com/loginDeepControl?... URL appears, leave Tab A waiting.

Tab B (new Termux tab):
  termux-open-url 'PASTE_FULL_URL_FROM_TAB_A'

Finish login in the browser. Tab A should finish. Then:
  origin auth status
  exit

Test in Termux (not proot):
  cd ~/storage/shared/!simon/obsidian/development/Sudoku
  git pull origin main

If pull works without a password prompt, auth is done forever on this phone.
