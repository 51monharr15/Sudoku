TWO WAYS TO REFRESH (pick one)
------------------------------

A) CODEBASE DOWNLOAD (what you do now)
   Codebase puts a snapshot on the phone. It usually has NO .git folder.
   So you cannot git pull until you switch to (B).

   After download lands in Sudoku (or you extract a .tar.gz into development/):
     cd ~/storage/shared/!simon/obsidian/development/Sudoku
     npm install
     npm run dev -- --host
   Chrome: http://127.0.0.1:5173/

   Staged (built site, like upload):
     npm run build
     npm run preview -- --host
   Chrome: http://127.0.0.1:4173/


B) GIT (one folder, one command updates)
   Why git: git pull origin main is the standard refresh; you see history and diffs.
   Why it was painful: Origin login needs the Origin CLI, which does NOT run in
   plain Termux (only inside Ubuntu proot). That is a platform limit, not you.

   One-time (when you choose git — same parent folder):
     cd ~/storage/shared/!simon/obsidian/development
     mv Sudoku Sudoku-download-backup
     git clone https://origin.cursor.com/git/51mon/Sudoku.git Sudoku
     cd Sudoku && npm install

   If clone asks for password: see documentation/GIT-AUTH-TERMUX.txt (one auth path only).

   Every update after clone works:
     cd ~/storage/shared/!simon/obsidian/development/Sudoku
     git pull origin main
     npm install
     npm run dev -- --host
