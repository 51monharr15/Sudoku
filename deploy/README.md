# Deploy (FTP)

| Path | Use |
|------|-----|
| **`website/`** | Upload entire folder to your web host |
| **`sudoku-studio-upload.zip`** | Same as `website/` |
| **`VERSION`** | Copy of repo root version (matches app UI) |

How-to docs: **`documentation/`** at repo root.

Rebuild: `npm run deploy:zip`
