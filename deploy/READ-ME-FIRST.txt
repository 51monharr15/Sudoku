SUDOKU STUDIO — READ THIS FIRST
================================

Everything you need to DEPLOY and USE the app is in this  deploy  folder.


WHAT TO UPLOAD TO YOUR WEBSITE (FTP)
------------------------------------
  ONLY this folder:

    deploy/website/

  Upload ALL files and folders inside  website  to your web host
  (public_html / www / htdocs). Overwrite old files.

  Do NOT upload  documentation , zip, or text files from  deploy .


OPTIONAL ZIP (same files as  website/ )
---------------------------------------
  deploy/sudoku-studio-upload.zip
  Unzip → upload the contents (same as  website/ ).


HOW TO GET THIS FOLDER ON YOUR PHONE
------------------------------------
  Cursor in Chrome:

  1. cursor.com → log in
  2. Left: Codebase (Early Beta)
  3. Tap  Sudoku
  4. Top: Settings → Advanced
  5. Tap  Download  (whole repo)
  6. Unzip on phone → open  deploy  → use  website  for FTP


DOCUMENTATION (how to use the app)
----------------------------------
  deploy/documentation/

  Start with:

    HOW-TO-USE-APP.txt
    UPLOAD-FTP.txt
    AFTER-UPLOAD-CACHE.txt


CHECK THE NEW VERSION WORKED
----------------------------
  Open https://YOUR-DOMAIN/ in Chrome (not the home-screen icon first time).

  You must see buttons:  Fill | Propose | Candidates | Strong
  and a row:  n=2  n=3  n=4

  If Strong is missing → old files or cache. Read AFTER-UPLOAD-CACHE.txt
